# 推理源码

源码来自 [Stareven233/YingMusic-SVC](https://github.com/Stareven233/YingMusic-SVC)，原项目为 [GiantAILab/YingMusic-SVC](https://github.com/GiantAILab/YingMusic-SVC)。保留作者改造的 Pupu → PC-NSF-HiFiGAN 两级推理方案和许可证。

本项目的依赖安装、模型下载、启动和使用方法以根目录 [README.md](../README.md) 为准。模型统一放在根目录 `models/`，具体文件位置见根目录 README 中的模型表。

pupu/ 是随项目保留的 Pupu 声码器源码，来源和适配说明见 [THIRD_PARTY.md](../THIRD_PARTY.md)。
